# OZ GPS 0.13.0

- Twelve new destination motifs are available in both Modern and Classic themes: three bunkers, three modern cities, two sci-fi cities, two ancient cities, a bandit camp, and an ancient ruin.
- The new icons can be used for private, group, and global markers. Existing markers and icon selections remain unchanged.

Existing world settings and marker data remain in place. Requires Java 25 and Rising World PluginAPI 0.9.3.2.
