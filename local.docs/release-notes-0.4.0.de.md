# OZ GPS 0.4.0

Diese Version ergänzt Marker-Verwaltung und Teleport-Cooldowns pro Marker-Typ.

## Highlights

- Berechtigte Spieler können Marker-Namen und Marker-Icons im GPS-Raster und im Teleport-Overlay bearbeiten.
- Das Löschen von Markern nutzt jetzt eine optionale Bestätigung mit einer spielerspezifischen "nicht erneut fragen"-Einstellung.
- Admins können Teleport-Cooldowns pro Marker-Typ für statische, private, Gruppen- und globale Marker konfigurieren.
- GPS-Raster und Teleport-Overlay zeigen den Cooldown-Status, damit Spieler sehen, wann ein Marker wieder nutzbar ist.
- Der GPS-Spielerdaten-Tab zeigt jetzt Cooldown- und Laufzeitwerte fuer Support und Administration.
- Cooldowns fuer statische Marker gelten jetzt auch fuer statische Spawn-Teleports.
- Layout der Marker-Aktionen im Raster, Teleport-Dialog, Vollbild-Löschbestätigung und Speichern/Wiederöffnen von Bearbeitungen aus dem Teleport-Overlay wurden korrigiert.

## Installation

Bitte beide Plugins aktualisieren:

- `OZTools` `0.18.0`
- `OZGPS` `0.4.0`

Eine Datenbankmigration ist nicht notwendig.
