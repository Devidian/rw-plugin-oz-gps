# OZ GPS 0.3.2

This release updates the GPS UI/UX and aligns the plugin with OZTools 0.18.0.

## Highlights

- GPS grid cards and marker dialogs now follow the shared OZ plugin UI style more closely.
- The GPS overlay border, teleport dialog buttons, marker icon picker width, and marker naming flow were refined.
- The plugin welcome message is restored as a single colored chat line.
- New marker icon assets are bundled for GPS marker selection.
- The default `sendPluginWelcome` setting is now `false`.
- Bundled PluginAPI and Maven dependency versions are aligned with the release build.

## Installation

Update both plugins:

- `OZTools` `0.18.0`
- `OZGPS` `0.3.2`

No database migration is required.
